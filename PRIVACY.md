# Privacy Policy for Just Compare

**Last Updated:** October 18, 2026  
**Publisher:** The Maven Lab ([themavenlab.org](https://themavenlab.org))  

The Maven Lab is committed to protecting your privacy. This Privacy Policy explains how **Just Compare** handles your data.

---

### 1. Offline & Local-First Operation
* **Zero Telemetry:** Just Compare does not collect, record, or transmit any analytics, telemetry, or diagnostic metrics.
* **No File Uploads:** All file and directory comparisons, text alignments, intraline analyses, and merge operations execute 100% locally on your device. Your files, documents, and directory structures are never uploaded to any remote server or third party.
* **No Network Transmission:** Just Compare does not communicate with any external web services or APIs during normal usage.

---

### 2. Local Storage
Just Compare saves user configuration and temporary state solely on your local device within standard operating system application directories (e.g., `%APPDATA%\org.themavenlab.justcompare` on Windows):
* **Settings & Preferences:** Stored display options, comparison criteria, and font/layout settings.
* **Recent Comparisons & Sessions:** Locally stored file paths and named session definitions to allow you to reopen previous workspaces.
* **Crash Recovery Drafts (Opt-in):** If draft recovery is enabled, unsaved comparison drafts are saved locally for up to seven days so you can recover your work after an unexpected restart. These drafts are never transmitted externally.

---

### 3. Windows Explorer Integration
Just Compare offers optional, per-user context menu shortcuts in Windows File Explorer (e.g., *"Select as left file for compare"* and *"Compare to..."*). 
* When enabled, the path of the selected left item is recorded locally on your disk in your local configuration directory.
* Explorer integration does not grant elevated privileges, alter system-wide file associations, or track file operations.
* Integration can be enabled or removed from the application's **Integration** menu. Remove it before moving or deleting a portable executable. Cleanup on uninstall of a Store package must be verified before that distribution is released; it is not promised by the current portable workflow.

---

### 4. Children's Privacy
Just Compare is a general-purpose productivity utility that does not collect any personal information from any user, including children under 13.
